# Система оргструктуры и согласования документов (Вариант 24)

Проект представляет собой библиотеку классов для моделирования организационной структуры компании (в виде дерева подразделений) и гибкого маршрута согласования документов по полиморфным правилам.

## Основные возможности
- **Дерево подразделений (`Department`):** поддержка иерархии, поиск руководителя на N уровней вверх (`findManagerAbove`), рекурсивный сбор всех подчинённых вглубь (`getAllSubordinates`).
- **Сотрудники (`Employee`):** идентификация по `id`, поддержка ролей (`Role`), корректный контракт `equals/hashCode`.
- **Полиморфные правила согласования (`ApprovalRule`):**
    - `DirectManagerRule` — непосредственный руководитель (с эскалацией для начальников).
    - `DepartmentHeadRule` — руководитель подразделения.
    - `RoleBasedRule` — поиск сотрудника с заданной ролью в компании.
- **Движок маршрутов (`ApprovalRoute`):** пошаговое согласование, отклонение, аудит истории (`ApprovalRecord`), защита от согласования чужих шагов (`ApprovalException`).
- **Java 21:** использование `record`, `sealed interface`, `Collections.unmodifiableList` для защиты от утечки состояния.
